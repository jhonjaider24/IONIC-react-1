# IONIC React

Aplicación móvil de ejemplo creada con Ionic, React y TypeScript.

## Funcionalidades

- **Tareas:** agrega, marca como completadas y elimina tareas.
- **Cámara:** toma una foto y la muestra en pantalla.
- **Acerca de:** una breve introducción a Ionic.

## Tecnologías

- Ionic React
- React 19
- TypeScript
- Vite
- Capacitor

## Requisitos

- Node.js y npm instalados.

## Instalación y ejecución

Desde la carpeta del proyecto:

```bash
npm install
npm run dev
```

Vite mostrará en la terminal la dirección local para abrir la aplicación en el navegador.

## Comandos útiles

```bash
npm run build       # Compila y valida los tipos de TypeScript
npm run lint        # Ejecuta las comprobaciones de estilo y tipos
npm run test:unit   # Ejecuta las pruebas unitarias
npm run test:e2e    # Ejecuta las pruebas de extremo a extremo
```
